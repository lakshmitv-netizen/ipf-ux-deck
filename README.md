# IPF · UX Deep Dive — portfolio backup (live site)

Static build of a UX program-review deck, kept as a personal portfolio backup.
The site is passphrase-gated on load.

- Customer and competitor names/logos, usability-participant names, and teammate
  credits are anonymized ("name withheld") for confidentiality.
- Built from the deck source (kept in a separate private repository).
- Published via GitHub Pages; routing uses a URL hash (`#/program-review-jason`).
- To change the passphrase, edit `GATE_HASH` in `index.html` (see the comment there).
